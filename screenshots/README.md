# Screenshots

These screenshots were taken with a synthetic demo vault. Every item, username,
password and URL is fake; none of the data comes from a real Bitwarden account.

- `01-picker.png` — the search window with the demo item list.
- `02-search.png` — filtering the list (`git` matches GitHub and GitLab).
- `03-password-prompt.png` — the master-password dialog used when the vault is locked.
- `04-wrong-password.png` — the error shown after a rejected master password.

`fake-vault.json` contains the demo entries used for these screenshots.
